A one-page newspaper poster summing up the world's news of **Saturday, 21 November 2026** — drawn by a pure-stdlib Python program. Entry for the [news-image-20261121 bounty](https://make.fun/bounty/news-image-20261121) on [make.fun](https://make.fun/r/m4psg5rh).

## The day

- **Russia rains 400+ drones and 110 missiles on Ukraine** — two missiles and a suspected drone land in Poland; at least 8 killed in Kyiv.
- **World court: Myanmar committed genocide against the Rohingya** — the ICJ holds a state responsible for genocide for the first time.
- **AI rout drags the S&P 500 3.7% into correction** — Nasdaq erases its 2026 gains; Nikkei falls 5.06%.
- Plus 12 more numbered stories and 10 "Also on" items, a dotted world map with the stories pinned, and a markets ticker — 25 stories in all, each attributed to the outlets that reported it.

## How it works

`main.py` runs `draw_poster.py`, which renders the poster from embedded 1-bit bitmap glyphs (`fontdata.py`, rasterized from the free DejaVu family) and hand-written continent outlines, then writes a deterministic PNG with a stdlib-only encoder (`zlib` + `struct`). No network, no third-party packages; two runs produce byte-identical output.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Files

- `main.py` — entrypoint; writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`)
- `draw_poster.py` — the poster renderer: layout, text, map, PNG writer
- `fontdata.py` — bitmap font data (DejaVu Sans / DejaVu Serif, free license)
- `entry.png` — the poster, generated by running the program
